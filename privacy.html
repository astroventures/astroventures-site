Privacy Policy

Astro Ventures LLC · Last updated October 9, 2026

This policy covers "AV Workspace MCP", an internal tool that Astro Ventures LLC uses to let its own authorized users work with their own Google accounts (Gmail, Drive, Calendar, Docs and related services) from their own computers. It is not offered to the public.

What the tool accesses

When an authorized user signs in with Google and grants permission, the tool can read, create and send items in that user's own Google account, within the permissions the user approves on Google's consent screen. It accesses only accounts whose owners have signed in and approved it.

How the data is used

  • Google user data is used only to perform the actions the signed-in user requests.
  • It is processed on the user's own device. Sign-in tokens are stored on that device and are not sent to Astro Ventures servers.
  • We do not sell Google user data, use it for advertising, or share it with third parties, except as needed to perform a task the user requests or as required by law.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

A user can revoke the tool's access at any time at myaccount.google.com/permissions. Revoking access stops all further access. Copies a user has saved to their own device remain under their control.
